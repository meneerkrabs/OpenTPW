## The Dutch front-end smoke presses the Dutch window keys (October 17, 2026)

`--front-end --smoke-test --language Dutch` failed at "the injected V opens the All Visitors window". The game was right and the smoke wrong: tp.exe's key group initialiser (`0x40cb80`) copies the 21 letters of the language's `KEYBOARD.str` over the window shortcuts, and the Dutch file (`KAIVWBFLTMOCWBAHSO,.P`) makes B the All Visitors key, V the All Attractions key and K the Buy key, so the injected V opened All Attractions. `Input.ApplyKeyboardStrings` already did this (and `KeyboardStringsTests` pins the Dutch letters); the smoke hard-coded English V and B. It now injects `Input.ChordKey( InputButton.AllVisitors )` and `Input.ChordKey( InputButton.BuyAttractions )`, so the same steps pass in every language. No game behaviour changed.
