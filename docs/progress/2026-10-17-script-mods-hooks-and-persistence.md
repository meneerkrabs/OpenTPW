## Script mods: hooks, failure counters and saves (October 17, 2026)

- **Hooks** (`[EXT:script-mods]`, `source/OpenTPW/World/Guests/Decisions/ScriptGuestDecisions.cs`): `GuestSimulation` wraps its base policy (faithful or smarter) in `ScriptGuestDecisions` when script mods are enabled. `scoreAttraction`, `joinQueue`, `leaveQueue` and `wanderGoal` map onto `ScoreAttraction`, `DecideAdmission`, `DecideQueuePatience` and `ChooseWanderGoal`; each mod gets the previous result as `prev` in the resolved, saved mod order, and a failing mod returns `prev`. Results are typed and range-checked (a score is an unsigned word, a wander goal is `y * 1024 + x` inside the map). Views are plain read-only tables with ASCII keys and stable ids. `rng` hashes (park seed, mod id, hook name, guest birth id, park turn, draw ordinal). The seam gained `IGuestDecisions.BeginTick()` and the map size in `DecisionContext`; with no script mod nothing is wrapped and every pin and save byte is unchanged.
- **Identity split.** Script mods need birth ids, so the smarter-guests identity state (seed, counter, birth ids) is now also created for a script policy, without any smarter rule or the extension's record; the `SmarterGuests` save section is accepted and required whenever a `ScriptMods` section is present.
- **Budgets.** Defaults are 5 000 steps per call and 50 000 per tick and mod, from `--guest-report --guest-mod` runs on the scenario and the four level parks (heaviest call 124 steps, busiest tick 3 188 steps and 64 calls; factors of 40 and 15). The numbers are in `docs/SCRIPT-MODS.md`. The corpus golden hash moved with the call budget; `BehaviourVersion` stays 1 because no save held it before.
- **Failure semantics.** Per mod: runtime-error, budget and invalid-result counters and a disabled flag, saved and hashed. A mod is disabled after 16 failures (one warning in the log); skipped calls after a tick overrun count once per tick.
- **Saves.** Optional `ParkResumeSnapshot.ScriptMods` section keyed by mod id (canonical `state`, counters, flag, behaviour and API version), validated strictly on load, refused on a version mismatch with a clear message, joined to `WorldStateHash` only while a script mod is on. `SchemaVersion` stays 21 (as for the smarter-guests section); older builds refuse the section. Pins: `ScriptModsFixedRunHash` (the example mod) and `ScriptModsAllHooksFixedRunHash`; a resumed park stays hash-equal to the uninterrupted one.
- **Example.** `opentpw.example.patient-guests` is wired (`joinQueue` relaxes the excitement gate for happy guests, `leaveQueue` ends very long waits, two counters in `state`); off by default and out of the web build. Against the baseline (`--guest-compare`, 8 seeds, extended scale) the scenario's boarded rate rises 0.560 to 0.630 (+8.7 SE) and its ride-use Gini falls 0.197 to 0.108.
- **Report.** `--guest-report --guest-mod <folder|id>` runs the report with mods on and prints each script mod's calls, steps and failures.
- **Not yet.** The browser check and the example in the web build (phase 5), `--test-mod` and read-only event hooks (phase 6).
