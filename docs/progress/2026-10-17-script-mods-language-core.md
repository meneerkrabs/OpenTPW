## Script mods: the TPW Script language core (October 17, 2026)

- **Decision.** Mods are data plus sandboxed scripts; native code and assemblies are never loaded (`docs/MODS.md`). The language, its execution contract, the `state` schema, the planned saves and the hook API are in `docs/SCRIPT-MODS.md`.
- **Language core** (`source/OpenTPW/Scripting/`, `[EXT:script-mods]`): our own lexer, single-pass parser and bytecode interpreter for a Lua-syntax subset with 64-bit integers only (overflow and division by zero are runtime errors, `//` truncates toward zero, `fx(1.25)` fixed-point literals), no closures, coroutines, metatables, try/catch, top-level mutable variables or floats. The top level holds only functions and literal constants. A fixed host whitelist (`min`, `max`, `abs`, `clamp`, `fxmul`, `fxdiv`, `len`, `has`, `keys`, `push`, `pop`, `del`, `rng`) is resolved at compile time; there is no reflection.
- **Budgets and limits.** A deterministic step counter in the dispatch loop (10 000 steps per call, 200 000 per tick by default), a call depth of 32, 512 KiB of accounted memory per call, and static limits on source bytes, tokens, nesting, functions and string length. `ScriptLimits.BehaviourVersion` is the version saves will record.
- **Transactional `state`.** A call runs on a copy-on-write view; only a successful call with a valid, typed result commits. Failures (runtime error, budget, invalid result) return the caller's `prev` and roll back. The canonical serialiser (sorted keys, NFC strings), parser and validator exist; save wiring does not.
- **RNG.** `rng(n)` is a stateless hash of (park seed, mod id, hook, guest birth id, park turn, draw ordinal); values are pinned by a test.
- **Tests.** Grammar, an escape and denial-of-service corpus, limits at their boundaries, rollback, the canonical round trip, step budgets identical across runs, and a golden hash of a script corpus for the windows, macOS and ubuntu CI runs. `Scripting/` joins the `DeterminismTests` forbidden-API scan.
- **Not yet.** No manifest changes and no hooks into `GuestSimulation` (phases 3 and 4 of the plan). Open: whether `string.Normalize` behaves identically in the browser build (the golden corpus includes an NFC case to show it).
