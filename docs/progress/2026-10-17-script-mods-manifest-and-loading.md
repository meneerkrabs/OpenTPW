## Script mods: manifest, loading and safe mode (October 17, 2026)

- **Manifest** (`[EXT:script-mods]`, `source/OpenTPW/Mods/ModManifest.cs`): `content.scripts` holds `files` (1 to 8 mod-relative paths, the usual path rules) and `hooks` (hook name to function name; only the v1 names `scoreAttraction`, `joinQueue`, `leaveQueue` and `wanderGoal` are accepted). `scriptApi` is a version range checked against `ScriptLimits.ScriptApiVersion` (`1.0.0`, beside `BehaviourVersion`); it is required with scripts and refused without. Parsing stays strict.
- **Loading.** `ModSet.Resolve` reads each script file once; the digest in `ContentSha256` and the compiled program come from that one read, and the bytes stay in memory (`ResolvedMod.Scripts`). Caps: 8 files, 64 KiB per file, 256 KiB in all (against 20 000 files and 2 GiB for mods in general). A compile error, an oversized file, a missing hook function or a wrong parameter count refuses the mod with the file and line (new refusal kind `Script`). Later phases must run the retained programs and never re-read the path; a test changes the file after resolve and checks the retained bytes are still the hashed ones.
- **Classification.** A mod with scripts changes the simulation unless all its hooks are UI-only (none in v1), so it is in `SimulationMods` and recorded in park saves.
- **Mods screen.** "Contains scripts" in the details in all nine languages, the compile error as the refusal reason, and a safe-mode notice.
- **Safe mode.** A marker `script-mods-starting.marker` in the config folder is written before the renderer is created when script mods are enabled, and removed after 15 seconds of frames or at a normal exit. If it is found at startup, or `--safe-mode` is given, that run refuses every script mod without reading or compiling it (refusal kind `SafeMode`) and shows a notice; the marker is deleted when seen. Smoke tests ignore the marker. The browser has no safe mode (no marker file, no community mods).
- **Example.** `content/mods/opentpw.example.patient-guests` (off by default) with `leaveQueue` and `joinQueue` scripts; it compiles and has a golden content digest, and does nothing until the hooks are wired in.
- **Not yet.** No hooks into the guest simulation, no `ScriptMods` save section (phase 4).
