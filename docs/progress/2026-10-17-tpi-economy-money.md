## Theme Park Inc runs its money (October 17, 2026)

The experimental Theme Park Inc slice now runs the park's **money** on Theme Park Inc's own balance keys, and still refuses staff, research and challenges. Read statically in the no-CD `Game.exe` against `tp.exe`; nothing was run and none of it is compared with the running original. Details and the key map: [THEME-PARK-INC.md](../THEME-PARK-INC.md#theme-park-inc-economy-money-only).

- **The capability is split** (`EditionCapabilities`): `Money`, `Staff`, `Research`, `Challenges`; `Economy` is their conjunction, so it is true only for Theme Park World, which keeps every part on. `EconomyRules` (`Full`, `ThemeParkIncMoney`) tells a `ParkEconomy` which systems run; every Theme Park World park runs `Full`, and no determinism pin moved.
- **Settings built from Theme Park Inc's keys**: Theme Park Inc's `Standard.sam` lacks 86 of the 152 fixed keys the Theme Park World economy reads (the executable's schema rows `0x9966C0`, block `0xA01A6C`), and no theme layer supplies them. `BalanceSettings.ForThemeParkInc` reads the shared money keys (bank, `LoanInfo[n]`, `Costs.*`, the entry-fee perception: the same readers as Theme Park World) and fills nothing else, so no Theme Park World value is invented; the object catalogue gains `Info.ExpectedPrice`, `Info.WorkingLife`, `Upgrades[n].RunningCost` and `Upgrades[n].CashPerBrainPoint`.
- **What runs**: starting cash 50,000 and admission fee 25; build, upgrade-less purchases, path, queue and track charges (`[EXT:tpi-free-builds]` is retired); scrap refunds with Theme Park Inc's condemned-object branch (state 4 refunds nothing, `0x5E765B`); loans and the monthly bank step (oracle X8, X9); bankruptcy; the calendar; monthly running costs per object (`0x5DEFFF`: the current level's `RunningCost`, nothing in state 1 or 4); the entry-fee judgement (the divisor is data: 6 in Theme Park Inc's global file, 4 in arabian's layer); Theme Park Inc's arrival-group routine (`0x5BCD60`, oracle X7: the weather percentage and the single-precision 0.01); no Buy Land (`Costs.MapCell` is in the data and read by no instruction found); the HUD shows cash, date and entrance fee and prices each build row.
- **Refused or left open**: staff, so rides neither wear nor break down and no upgrade is installed (`NeedsStaff`); research (the whole catalogue is on offer); challenges, golden tickets, missions; Theme Park Inc's weather (the arrival percentage is always 100); guests paying for rides (`InitPricePerUse` 20 and `ExpectedPrice` 25 are read, not charged). New register entries: ECON-060 (the statistics accumulator `+0x938` and the month handler's order), ECON-061 (the scrap value's thing-flag branch left out), ECON-062 (ride prices), ARRIVAL-008 (no Theme Park Inc weather state). New labels: `[EXT:tpi-money-only]`, `[EXT:tpi-no-research]`, `[EXT:tpi-park-open]`.
- **Tests**: `ThemeParkIncEconomyTests` (synthetic: capability split, settings, catalogue keys, charges, loans, bankruptcy, running costs, scrap branches, refused systems, the arrival rule) and `ThemeParkIncPlayTests` over the corpus (settings of every world, the entry-fee divisor, every buildable object priced, a headless park that charges a path and a ride, pays its running cost and advances its calendar).
