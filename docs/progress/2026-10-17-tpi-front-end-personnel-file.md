## Theme Park Inc starts at its Personnel File instead of asking for a zone (October 17, 2026)

Phase 1 of a real Theme Park Inc front end. Theme Park Inc has no island lobby: it boots into its 3D intro world and runs front-end screens as overlays, and its start menu is the Personnel File. Read statically in the no-CD `Game.exe` (SHA-256 `77ea0c41...967a`) and drawn with OpenTPW's own widgets:

- **Layout tables from the executable.** `tools/ppc-analysis/lanes/ui/tpi_exe_layouts.py` reads the Personnel File (`[BIN:TPI-EXE:0x9c0fbc]`, 39 nodes) and the generic confirm table (`0x9b18bc`, 5 nodes) with the same stream grammar as the Theme Park World generator and writes `ThemeParkIncLayoutTables` (rectangles, ids, help ids, model names; no game data). The names resolve against Theme Park Inc's `ui.wad` (an unresolved hash is an error). The grammar was checked by parsing all 86 tables of the executable.
- **Strings.** Theme Park Inc's `UITEXT.str` has 994 records with its own ids; `ThemeParkIncText` names the ones the screen uses (19 to 35, 773) and `THEMENAMES.str` entries 0, 1 and 3 name the zones. `UiStringTable.Entry` reads a record by the file's own number.
- **The screen.** `ThemeParkIncFrontEnd` draws the window, four player slots, name box, Enter Game / Load A Game / Delete Player, Coaster Design Kit, Quit Game and the mugshot from Theme Park Inc's models with the PERSONNELFILE fonts, and the quit confirmation. Enter Game starts the existing slice in science (the original's default for a new player, `0x56ab40`); an OpenTPW zone chooser (`[EXT:tpi-front-end-zone-chooser]`) offers Polar Zone and Arabian Nights, which the original reaches only through its campaign. One OpenTPW player (`[EXT:tpi-front-end-one-player]`, the `[EXT:no-player-profiles]` decision): Load, Delete, the name box and the Coaster Design Kit are drawn inactive.
- **Routing.** `EditionCapabilities.PersonnelFileFrontEnd` (on for the slice, `[EXT:tpi-front-end-phase1]`) lets `--front-end`, or a start without a world and with only file, language, display or sound options, open the page on Theme Park Inc data; `--load-original-level` still starts a world directly and every other option keeps its refusal.
- **Left for later phases:** the 3D intro world behind the page, sound, the start-up movies, profiles and saves, the stock labels, the setup wizard's and the browser's up-front zone choice (the browser copies a zone's files at setup).
- **Not verified:** how the page looks on screen (no capture was taken), text placement inside the controls, the quit window's text area. `ThemeParkIncFrontEndTests` checks the tables, string ids, routing, that every model loads with resolving textures over the retail corpus, and a headless draw.
