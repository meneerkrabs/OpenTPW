## ADVISOR-025: the lobby shows the saved key count (October 18, 2026)

The island lobby now shows the player's saved Full Simulation key count in the original top-right key slots (the key icon `gkey` and the "%d x" count, the children of the key group 0x1E0EC in the Lobby layout), as tp.exe's panel refresh `0x4B9340` does for a positive count outside Instant Action. OpenTPW has no player profiles (`[EXT:no-player-profiles]`), so the count is read once from the one player's saved ledger when the menu is built; missing, corrupt or other-mode progress hides it and nothing is written. ADVISOR-025 is narrowed, not retired: the advisor timer's live refresh, the EA/EB affordability art and effect 0x61 (which runs while the count meets the selected record's threshold, not when it drops) remain open. Details in [the lobby key panel notes](../reverse/LOBBY-KEY-PANEL.md) and [the proposal](../proposals/advisor-025-plan-island-key-panel.md).
