## ECON-023: Retained breakdown state on original import (October 18, 2026)

Added the [ECON-023 proposal](../proposals/econ-023-specify-breakdown-state-ownership.md) on October 18 and implemented its bounded part in #506 (merged October 20 with exact-head CI green): an original TPW save's broken-down or condemned attraction (saved state 1 or 4) keeps its broken state on the visitor bridge after its script is attached, only for a unique matching saved, economy and runtime owner, with synthetic regressions. tp.exe keeps such an object closed every tick (`0x4e0e00`, `SetState` `0x4e0e60`) until a repair sets state 0 (a maintenance request can also move it to state 2, which is closed as well). ECON-023 stays open: the one state word is still split between the visitor bridge and the economy's broken flag.
