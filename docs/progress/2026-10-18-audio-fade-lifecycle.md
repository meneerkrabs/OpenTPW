## Implement the bounded FADEOBJ lifecycle (October 18, 2026)

FADEOBJ now releases script records into service-owned tails when SoundQuality is strictly above the loaded sound.sam threshold (supplied default 50, threshold 30). KILLOBJ remains immediate. One shared monotonic poll phase uses post-scan delays of 100/250 ms, integer-volume feedback includes enabled groups without applying them twice, child containers stop on their first poll, and sample-backed sentence fades survive segment/decode gaps. Pending admission, quality downgrade, stop-all, leave-park, disable and shutdown have terminal guards. The existing Audio Quality slider now persists the setting; absent options use the loaded default and Cancel restores the previous choice.

Synthetic regression coverage follows the [bounded lifecycle contract](../proposals/audio-040-plan-soundquality-fade-mode.md), including script ownership, all seven parser subtypes, quality/config migration, shared phase, group changes, decode races and late callbacks. AUDIO-040 remains open for original x87 quantization and host scheduling qualifications; AUDIO-038 is unchanged. No original program or media was executed. Local C# tests could not run because dotnet is absent; CI and independent review remain required.
