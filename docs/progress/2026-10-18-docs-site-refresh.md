## Documentation and website refresh: extensions, mods, pools and texture packs (October 18, 2026)

- **Discoverability.** The README has an "Extensions and mods" section with the official extensions and their defaults (pools and pool guest art on by default), how to switch them off, data mods, script mods and local texture packs. The front page gained "You can" entries for pools and for mods, every site navigation has a "Mods" link, and the documentation index lists [Extensions and mods](../MODS.md), [Script mods](../SCRIPT-MODS.md) and [Pools](../POOLS.md) under "Start here"; "Enhanced textures" is now "Texture packs" there.
- **New content.** [MODS.md](../MODS.md) has a defaults table, a quick start for a first data mod and how to enable the shipped example script mod; [SCRIPT-MODS.md](../SCRIPT-MODS.md) has a quick start, a first hook and a hook quick reference; [POOLS.md](../POOLS.md) starts with a section for players; [TEXTURE-PACKS.md](../TEXTURE-PACKS.md) has a "Make your first local pack" list.
- **Corrections.** The README lists all nine languages, links stable (hourly) releases instead of pre-releases and notes that the pinned .NET 11 SDK is a release candidate. Water rides and go-karts are described the same way in the README, the front page and the feature matrix (they build, run and save; jumps and tunnels are missing). Original saves are described as importing guests (except queued, boarding and riding ones) and research. MODS.md says the script hooks run on the desktop (not in the browser), and its manifest examples use `>=0.8.0` instead of a range that refuses every release so far. The "Not done yet" list of POOLS.md now holds only real gaps, CONTENT-KIT.md no longer calls the pools planned, the Theme Park Inc page no longer names v0.7.19 or PR #146 (the desktop edition chooser has been in every release since v0.8.0), and the front page no longer mentions an optional texture pack (none ships).
