## Mods and extensions explained on the site and README (October 18, 2026)

The README and the front page now have a section on extensions and mods: official extensions against community mods, the Extensions and mods screen, the pools extension (on by default, with its own textures, objects and hi-res 2x visitor sprites with swim animations, switchable off, not in Theme Park Inc runs), optional texture packs, data mods and script mods, with the reason for TPW Script instead of Lua. A new [modding guide](../MODDING-GUIDE.md) shows the folder layout, a minimal manifest, where to put a mod on each platform, a data override, a script taken from the working example mod, how saves record mods and what is not possible. The stale "hooks are not wired in yet" line of [MODS.md](../MODS.md) now says that script mods run on the desktop, and the pools page no longer lists merged phases as not done. The docs index lists the guide, the mods pages and the pools page under the featured documents.
