## Particle follow-up: register text, seat-head cache and the loading beams (October 18, 2026)

Three low findings from the after-merge review of #425. The register text now agrees with tp.exe: `0x51BFC0` is the sound submit, and the upgrade's call to it (`0x55A2E5`, global `cat_rides` 0xB8) is the wired upgrade sound, while the scoped message after the build effect is `0x51C640`, which stays unwired. The track renderer no longer allocates a seat-head array per vehicle per frame; the flags are cached per vehicle variant. The bumper and kart loading beams (`0x549C60`, raised only for a rider whose head dummy exists) no longer assume every rider is seated before the first draw: the controller asks a host-supplied source (`SeatHeadSource`, read from the vehicle mesh without drawing) and raises no beam where the dummies are unknown, such as a host that never loads the model.
