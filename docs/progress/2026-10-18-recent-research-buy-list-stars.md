## Recent-research stars in the TPW buy list (October 18, 2026)

The buy list now selects the empty box, owned tick or recent-research star directly. Four capacity-three rings remember paid research completions by `Info.WhichUIType`. Duplicate upgrade completions and paid add-ons consume slots; initial free items and propagated free levels do not. Buying masks a star and selling the last copy can reveal it again until a later completion evicts its ID. Auxiliary tool rows remain empty, and the existing model size and transforms are unchanged.

Host saves preserve the physical ring state, including scratch words and inactive slots; older saves start with empty history rather than inferring chronology from sorted completed projects. Native TPW import reads the world-referenced analyser with type and bounds checks. Export with explicit research state patches only the four rings' 68-byte range, including an explicitly empty history; without that option the template history stays. Malformed present state is rejected under a defensive host policy. Only the new presentation property is excluded from the world hash; research completion, progress and effort remain hashed.

UI-050 is retired for the implemented TPW contract. The TPW event producer, ring writer, reader and numeric-cell frame selector were resolved by static inspection. This does not establish Theme Park Inc's event policy, which remains disabled, or change the separate UI model transform approximations. No original game was executed and no rendered-pixel equivalence is claimed.

Synthetic C# regressions cover the paid completion branch, duplicates, category isolation, four-event eviction, actual buy-list `DrawModel` frames 0/1/2, purchase/sell masking, auxiliary rows, save continuation, older saves, malformed records, deep copies, native round trips, unrelated-byte preservation and hash controls.
