## Saves and economy: script run state, research export, new-park things (October 18, 2026)

Fidelity round 8, package 5. The original-format writer grew by the research lab and the park's fixed things, the RSSE import by the scripts' run state, and five open IDs moved.

- **Script run state (SAVE-010, DET-013)**: the Clock block's first word is the game clock the saved scripts count from. The Fantasy corpus seaplane is saved inside a `WAITANIM` with its deadline (`+0xA0`) 4,873 ms past the clock (185,660,000 against 185,664,873); `0x553783`/`0x553828` store `clock + wait` there and rewind the program counter, `0x55641B` stores `+0xC4` the same way. An imported original park now starts its script world's clock at that word and every matched script resumes at its saved program counter with stack, heap, variables, limbo table, result register, TURBO/DIPMUSIC/reverb/speed words, walk float, WAIT4ANIM deadline and timer (`RideVM.ImportSavedRunState`, `RideScriptWorld.ImportClock`). A script with a child record, or whose record does not fit this install's script, keeps its fresh state and is reported; a script saved inside a `TRIGWAITANIM` triggers again (its animation is not restored). The pinned determinism hash is unchanged (imports only).
- **Research export (ECON-017 retired)**: `OriginalResearchExport` writes the lab (256 projects, 5 groups, tail) and the object controls (`+0x10`, `+0x14`) from the park's research. The fill `0x5031A0` and `0x504580` define the order; the four `restart.INTS` the original wrote hold exactly OpenTPW's new-park table for their theme (48, 48, 44 and 46 projects), so the table is built, not carried, and only the shipped Easymode save lists a subset. The group output formula `(effort x 100 / sum) x work load / 100` and the control level rule (levels without a research cost count as finished) were read at `0x5031A0`, `0x503330` and `0x504580`.
- **New-park things**: `SaveNewParkThings` builds the park analyser (73,536 bytes), the advisor controller, the tag system, the UI message receiver and both HQs from the constructors and serializers; they equal the four restart saves byte for byte.
- **Staff pool (SAVE-004 retired)**: `0x5084F0` never expires a candidate whose on-pointer byte is set and `0x5083B0` clears the flag when a placement tool ends (and removes the candidate when the placement was made): a flagged candidate of a save now stays without expiring until the next tool exit (`ParkStaff.StaleOnPointerId`).
- **Customers row (ECON-057 retired)**: the shop and sideshow windows format UITEXT record `0x1CC` ("{0x19} of {0x1A}", `0x4B0423`, `0x4B18E6`) with the customers and the customers plus walk-aways, matched by parameter type as the formatter `0x6ACD60` does.
