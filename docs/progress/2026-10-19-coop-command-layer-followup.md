## Co-op C1: the winning screen and the Totem's run as commands; a ring for the command log (October 19, 2026)

A follow-up to the command layer ([COOP.md](../COOP.md)). The winning screen's exit (Resume Game, Escape, the right click) no longer removes the Instant Action finale from the HUD: it issues a `DismissFinaleCommand` through `Level.Commands`, and the developer panel's open and close button for the prototype Totem issues a `SetPrototypeRunningCommand`. Both have new kind tags (22 and 23, next to the prototype's place and remove; 22 is the tag the economy branch gives the same command) and pinned bytes in the schema test, and the static guard now refuses a direct call of either mutator from the tool layer. The in-memory command log is a ring that overwrites its oldest entry in constant time instead of shifting 65,536 entries on every command of a long bulldozer drag; its order and kept entries are those of the old list. A seeded fuzz test throws commands of every kind with off-map cells, unknown and negative ids, bad rotations and line modes at the executor: none throws, and every refused one leaves the world hash unchanged. COOP.md now quotes the plan's later record that the user approved the proposed `online-coop-*` labels. Single player and every determinism pin are unchanged.
