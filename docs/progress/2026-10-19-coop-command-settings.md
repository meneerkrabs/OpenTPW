## Co-op C1: the park's settings as commands (October 19, 2026)

Second part of co-op phase C1 ([COOP.md](../COOP.md)). The HUD windows' edits of the park are now commands through the park's funnel, like the building edits before them: the park's door and its keys, the rides' open buttons, the ride window's settings, the entrance fee, shop and sideshow prices and shop settings, loans, hiring and dismissing staff, staff names, training budgets, the research lab (effort, project and workload), challenge answers, maintenance calls, ride upgrades, the park's name, the cheats and the game speed with its pause. Each command checks what the economy would refuse before it runs, so a refusal changes nothing, and the scripted build session that replays with the same world hash after every tick now includes them. The static guard refuses the old direct calls; land, pools, staff placement and the coaster tool remain for the last part. No determinism pin moved.
