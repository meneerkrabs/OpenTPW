## Co-op: the HUD windows' settings become commands (October 19, 2026)

The second part of the co-op command layer ([COOP.md](../COOP.md), "Settings"; `[EXT:online-coop-commands]`): every setting the HUD's windows change now goes through the park's command funnel as a `ParkSettingCommand` (kinds 25 and 30 to 53). That covers the park door, the entrance fee, attractions open and closed, the ride window's settings, prices, prizes and shop settings, training budgets, the research lab, loans, upgrades, maintenance calls, the challenge answer, renaming and dismissing staff, patrol areas, the park's name, the game speed and the cheats. Each command names its object by attraction id, keeps to the window's ranges, checks what the edit would refuse and then makes the park's own call, so single-player play and every pin are unchanged. Each command keeps its control's rules, so a peer or a log cannot do what the window would not: a condemned ride takes no door, call or upgrade command and a ride with an unfinished track no door command (the ride window's refresh, tp.exe 0x4ad4e0), the ride speed keeps to its slider's range and the shop quality to its three steps. An answer names what the player saw (the challenge's offer, the loan's amount, the repayment's balance). The loans dialog's list build, which stores hashed credit tests, is a command too, and so are the developer object panel's open-all and close-all, which still open and close every object without the reopening guard. The HUD's speed status goes through the same commands, and the challenge answer no longer has a direct path around them.

The command layer's guard now refuses every converted settings mutator in the tool layer. Still listed for the next part are hiring with the staff placement, land, pools and coasters. `ParkCommandCodecTests` pins the bytes of every new kind and refuses each one's out-of-range fields. `ParkSettingCommandTests` checks every setting, its refusals and malformed text on a level without game data. `ParkSettingCommandLevelTests` acts on placed rides and replays a recorded session of settings on a twin park with the same world hash after every tick. Tests whose HUD had an economy other than its level's now attach it to the level, as the game does.
