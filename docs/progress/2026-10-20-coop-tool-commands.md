## Co-op: the land, staff, pool and track tools become commands (October 20, 2026)

The third part of the co-op command layer ([COOP.md](../COOP.md), "Tools"; `[EXT:online-coop-commands]`): the land tool, the hire and the employee in hand, the pools extension's tool and wave machines, and the kart and water rides' track tools now hand their writes to the park's command funnel as `ParkToolCommand`s (kinds 54 to 83). A tool keeps its own state between clicks and issues one command for each write it made before, at the same moment, so single-player play and every pin are unchanged. The Buy Land tool's purchase is one command with its two fence posts, checked against the fence's lattice and validated again with the money. The hire, the placement, its cancel, the pick-up and the drop are commands, and the employee in a player's hand is now the level's state rather than the tool's, so the frame's reconcile keeps a member a replayed or a peer's command picked up. Each cell of a pool stroke, the stroke's undo (in chunks when a stroke holds more cells than one command takes), each slide piece, each bridge and the wave machine window's tick are commands. A track line, its undo and the edit tool's cut are commands that walk the circuit again, while the tool's step after the walk (it ends, the queue tool follows, or a Ctrl click restarts it) stays on the issuer's machine. The line tool's walk to the track's open end sets the walked tiles' overlap words that Backspace reads, so it is a command too, and so is a track add-on's walk, now without the tool's step. A full thing pool now refuses a hire before its placement ends, where the hire threw after it.

The guard now refuses the land, staff placement, pool, slide, bridge and track writes in the tool layer; only the coaster tool and its panel are still listed for the next part, with the developer sandbox load for C2. `ParkCommandCodecTests` pins the bytes of every new kind and refuses each one's out-of-range fields, and the fuzz test draws them all. `ParkToolCommandLevelTests` drives the staff and pool tools on a level without game data and applies their logged commands to a twin that reaches the same hash; `TrackAddOnLevelTests` does the same for the track tools, including the line tool's reopening and Backspace after a cut, and compares the track layer and ride controller. `ParkLandTests` checks the land command's posts and verdict.
