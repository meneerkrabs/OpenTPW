## Co-op: the game's link to shared parks (October 21, 2026)

The game now has its side of the co-op socket ([ONLINE.md](../ONLINE.md), "Shared parks"; `[EXT:online-coop-session]`): a link under the online login that opens the socket with the desktop's header login or the browser's first-message login, says hello with the game's release and its simulation-changing mods in load order, and offers what a shared park needs: start or join a session, the open list of the game's own release, invitations, removals, the host's frames and messages between players. A lost connection, a deploy or a silent server opens a new socket and resumes the session, so the host can resend its frames from the last one the server relayed; another game of the account stops the link until the player takes over, and a game that restarted leaves the session the server still names. Logging out closes the link. No screen or park uses it yet.

`CoopLinkTests` runs pumped online sessions against a loopback server: a session created, listed, joined and shared, invitations, kicks and refusals, a resume after a dropped socket, after a server restart and after the silence watchdog, two games of one account and a take-over, a restarted game leaving its old session, and a logout.
