## The advisor's construction stamp moves for every object the game constructs (October 22, 2026)

The advisor's days since an object was built (tp.exe `0x4C9070`, read by the scan callbacks of the messages 60, 71, 73-75, 77-79 and 81) count from the park's `mLastObjectBuilt` (`+0x21C30`). The common object constructor `0x004DB090` writes it with the park time on its single exit (`0x4DB7A3` calling `0x4C7680`), and its five callers are all constructions: the build commit `0x529E10` (`0x529FD5`), which a purchase and the Move tool's re-placement both reach; the park setup's gates and lights (`0x515BE1`, `0x515C94`, after the park init at `0x5159C8`); the Instant Action finale's End (`0x516B8B`); and an arrival vehicle's first trip (`0x51A57E`). REA's callers and a byte scan for call instructions agree, `0x4C7680` has no other caller, and the loader `0x5179C0` constructs no object through the constructor but reads the saved word back (`0x4C7289`). OpenTPW moved the advisor's record only on `ObjectBuilt`, a purchase or a Move re-placement. The vehicles and End get their economy record through `Level.BindFixedItemMadeInPlay` (#764), which raised no event, so the first bus did not restart the count. They now register through `ParkEconomy.RegisterFixedItemMade`, which makes the same uncharged record and raises the new `ParkEventKind.FixedItemMade`, and the advisor moves its stamp on both events. The event is raised also for a type the economy catalogue does not know, which gets no record but was constructed all the same; a repeated research notification that adopts the live End constructs nothing and raises nothing. The stamp stays the advisor's own record: the event adds nothing the park save or the world state hash reads, so co-op digests are unchanged. An original save's import and a park's own fixed items at its start raise nothing; the gates and lights stamp turn 0, which the advisor derives when it attaches. The finale and arrival vehicle tests now attach an advisor through the level's own wiring and check that End and a seaplane, made a day into the park, restart its count (both checks fail without the change); a third makes both with an economy that knows neither type and checks that they stamp without a record and that the adopted End does not stamp again. Two advisor tests check that a registration moves no stamp and that a fixed item made in play leaves the park save and the world state hash exactly as a registration does. The related advisor, economy, finale, hash, co-op and resume tests pass (971, 51 skipped for want of game data), as do the CI tool contracts.
