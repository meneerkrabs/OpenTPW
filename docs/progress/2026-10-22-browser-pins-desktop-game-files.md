## Browser pins guard: desktop-only game files (October 22, 2026)

`BrowserPinsExclusionTests` now also catches a test that uses game code the browser page leaves out. The new `EveryTestFileUsingADesktopOnlyGameFileIsExcluded` reads every `<Compile Include="$(Root)/**/*.cs" ... Exclude="...">` item of `OpenTPW.Web.csproj` (the game's list, Client/Game.cs, Client/SignExport.cs, Render/ShaderCompiler.cs and the rest, and Common's SdlDisplay.cs). It collects the top-level types those excluded files declare with the existing `TopLevelTypes` reader. A type counts as desktop-only only when no compiled file declares it: the page's own stand-ins (`Browser/DeveloperPanels.cs` declares `ParkLayout` and `OnlinePanel`, and there are `ShaderCompiler`, `LegacySettings`, `SdlDisplay` and `SdlMovieAudioOutput`) and partial types with a compiled part keep their type. For those shared types the guard compares members instead, so `ParkLayout.DrawOriginalImport` or `ShaderCompiler.CompileProgram` count as desktop-only, as `Game.ResolveSaveDirectory` would once `Game` is split.

A failing file gets one line, for example `add SaveDirectoryTests.cs to DeterminismPinsExcludedTests in OpenTPW.Web.csproj: it uses Game (OpenTPW/Client/Game.cs), which the browser build leaves out`. Uses are read as before, from code only (no comments or literals). Game type names are common member names, so the guard ignores a name after a dot (`park.Settings`), an initializer target (`{ Cursor = 0 }`) and a name the test file declares itself (a field, helper method, local or parameter, which C# resolves first). With those rules the current test tree has zero hits. Taking `SaveDirectoryTests.cs` off the list, or adding a file that calls `SignExport.Run` (the two CS0103 failures of October 21 and 22), fails the guard. `TheDesktopOnlyGuardTellsGameUsesFromSameNamedMembers` pins the rules on small examples.

Open: a desktop-only type reached only through a fully qualified name (`OpenTPW.Game.X`) is not reported, and a name the test file declares anywhere hides the same-named game type in the whole file, not just in the declaring scope.
