## The kart and water line tool's advisor help 204 (October 22, 2026)

tp.exe posts advisor help 0xCC (204) when the kart or water line tool takes a click while it has no line start. OpenTPW now posts it too ([TRACKS.md](../TRACKS.md), "Messages"). The producer map had listed 204 as never said, and the restored advice extension posted it as the roller coaster tool started; that restored hint is dropped, as 344's was when its real producer was found.

- **The trace.** The line modes 0xB and 0x10 dispatch to `0x526CB3` (`0x525A1C`). With the start `0x81EDE4`/`0x81EDE8` at −1 the click stores the clicked cell as the start (`0x526D0F`) and as the first corner (`0x52FBD0`, `0x52FBF0`), pushes 0xCC at `0x526D41` and jumps to `0x527629`, the queue tool's post of 0x151: `0x59B590`, `0x5194D0` on `[0x7CF83C]`, `0x59A940`, the body of the help post `0x486B00`. Unlike 0x151 the post tests neither the replay word `0x785A2C` nor the link flag `0x816D60`. The placement presets the start at the station's exit (`0x52A1A0` at `0x525472`) and the track button's switch from the edit tool presets it at the open end (`0x530830`); `SetMode` `0x52F580` keeps both. So the click is reached only after a line closed its circuit with exactly Ctrl held and no queue to follow (`0x526F97`, `0x527146`), the state the HUD's tool click reaches since the queue end fix of the same day.
- **No withdrawal.** Neither `SetMode` withdrawal list names 0xCC (`0x52F245..0x52F326` in `0x52F200`, `0x52F5BF..0x52F6A0` in `0x52F580`), and none of the 57 calls of `0x486B40` and `0x59AA70` does. `ParkHud.ReportCellToolClick` therefore posts 204 at once instead of holding it behind the frame's mode change, so the tool ending before the next frame does not drop it, and the mode change leaves it pending.
- **Why the first map missed it.** The poster search read the id pushed in each call's own block; 204's push sits ahead of a jump into another post's tail. A byte scan for `push <id>` of each of the other 35 help ids that no post names finds none that leads to `0x59B590`.
- **The port.** `AdvisorToolHelp.TrackLineStart` (204, in `AdvisorToolHelp.All`, so a park that ends withdraws it like the other tool help) is posted by the HUD for a kart or water line click that gives the tool a start it lacked. The inventory row is `help` and `wired` (`content/data/advisor-producers.toml`). `RestoredAdvice` loses its 204 entry, the coaster tool's restored tip and the `TrackRideHelp` constant; its own mode withdrawal keeps the blueprint hint 202 only. The extension now restores 42 lines (thirteen of the first 55 stood down), and the counts in ADVISOR-SCAN.md, LIPS.md (with the ADVISOR-009 row), MODS.md, the README and the website follow: 236 of the 248 messages the original gives are wired, 103 are never said. The README and website figures also take in 344, which was wired before them.
- **What players notice.** With the extension on (the default), the advisor no longer says 204 when the roller coaster tool starts. With the extension on or off it says 204 at the line tool's click that sets a start after an exactly-Ctrl close, as in the original; 204's speech is about laying kart and water tracks, not the coaster tool.
- **Tests.** `TrackAddOnLevelTests.TheClickThatGivesTheKeptLineToolItsStartPostsHelp204` closes a kart circuit through the HUD's own tool click with exactly Ctrl held, then clicks again: only the click that stores the start posts 204. `TheLineToolOfAnOpenCircuitStartsAtItsOpenEndAndPostsNoHelp204` covers the track button's line tool. In `AdvisorToolHelpTests` both line modes post 204 for their first click and no path help after it, a line tool entered with a start never posts it, and the post outlives the tool's end. `AdvisorProducerInventoryTests` checks the row, and `AdvisorRestoredAdviceTests` that a mode change keeps 204 pending while it takes the blueprint hint and that 204 is posted with the extension off. The tests of the producer fail without it. Filtered local run (advisor, track, HUD, queue, path, co-op and mod filters, without game data): 2,086 passed, 86 skipped.
