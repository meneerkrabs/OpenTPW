## One pool bridge, with a preview, built without paths (October 22, 2026)

The buy window showed an empty panel for the pool bridge, offered separate east-west and north-south bridges, and refused to build a bridge before both outside ends had a path. There is now one **Pool bridge** row that builds in all four directions: the bridge in hand turns a quarter turn clockwise with the blueprint keys of an object (comma once, full stop three times), and the blueprint follows. The row's preview is the bridge's own committed Blender mesh, drawn by the ordinary buy-window preview, so the panel shows a turning bridge like every other item. A bridge no longer needs a path at its outside ends: the cell outside each end only has to be free ground, and the player lays the path later. Guests and staff enter only through an end that has a path, so a path laid afterwards makes the bridge walkable at once and a path removed closes that entrance. The bridge's own seven cells stay protected; the outside paths can be laid and removed, except that removing the last path end while someone is on the bridge is refused. The old refusal "an outside end without a path" and its text are gone in all eleven languages; the help texts mention the turn keys. `PoolBridgeResult.EndNotPath` was removed (the value is never serialized). Saves and the `PlacePoolBridgeCommand` bytes are unchanged for every direction, so old saves of either direction load, with or without end paths, and co-op replicates the same command. A bridge with no paths at either end changes no hash of a park without bridges.
