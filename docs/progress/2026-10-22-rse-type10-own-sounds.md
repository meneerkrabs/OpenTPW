## Ride scripts: the object type's own sound list (October 22, 2026)

The last ride-script sound type is served: EVENT, EVENT_EXT, ADDOBJ and ADDOBJ_EXT of type 10 play from the object type's own sound list, as tp.exe's object dispatcher does (`0x557686`). The list is the `cat_ride` category an object archive carries next to its models: the type loader registers it when the archive holds `cat_rideBANK.map`, `cat_rideSFX.map` and `BankHD.sdt` (`0x41F420`, `0x41408D`), and a type-10 sound is then submitted from it exactly like a sound of types 3-9 (the key's place, the event's own priority, range and flags; ADDOBJ keeps the handle under its slot, KILLOBJ, FADEOBJ and SETOBJPARAM reach it). A type without a list logs the original's message and plays nothing, before its key is looked at. No shipped script uses type 10; Jungle's loudspeaker is the one shipped archive with a list, so the feature is for mods ([RSE-VM.md](../RSE-VM.md#the-object-types-own-sound-list-type-10)). The README's ride-script row no longer lists it as a gap, and nothing of a ride script goes to the unimplemented-effect hook except the bounce opcodes of objects that do not draw their bouncing riders.
