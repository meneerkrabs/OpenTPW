## Parks started from an original save can be saved again (October 22, 2026)

Since the objects of an original save keep their saved animations, a park started from one (the Jungle Instant Action park and every loaded original save) could not be saved until each of those animations had started again: an animation that began before the object's own clock starts in OpenTPW has a start before zero, which the save refused as corrupt. That stopped the autosave, a save by hand, a shared park's capture and Restart Park's snapshot, which every original park takes as it starts (a loaded save then reported Restart Park unavailable). The save now keeps such a start, as far back as the original's 32-bit elapsed time reaches ([TPWS-PAYLOAD.md](../TPWS-PAYLOAD.md)), so these parks save, share and restart again. A corrupt saved control whose frame is beyond a float is now reported and skipped instead of stopping the import. The co-op join smoke found it.
