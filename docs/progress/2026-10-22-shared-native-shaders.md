## Faster start and smoother building on Windows (October 22, 2026)

On Windows every model part compiled its own copy of the same shaders: the lobby's islands compiled the lit object shader 146 times before the lobby could appear, and each newly placed ride compiled it again for every part. The engine now compiles each shader once and shares it, which drops the start from 156 shader compiles to 7 and leaves nothing to compile when an object is placed (issue #754: a black window for about 30 seconds before the lobby, and freezes of up to two seconds while building). The drawing is unchanged. New measurement options show where a start and a build step spend their time: `--startup-profile`, `--hitch-report` and `--perf-build` ([ENGINE-PERFORMANCE.md](../ENGINE-PERFORMANCE.md), "Start and build hitches").
