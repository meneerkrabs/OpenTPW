## Joining a shared park with a code (October 24, 2026)

Players can now join a shared park from the lobby with the code its host gave them ([COOP.md](../COOP.md), "Joining a shared park from the lobby"; `[EXT:online-coop-session]`). This is C2d-3a, the first part of joining from the game's own screens.

- The lobby's Build Together line opens a hub: share one of your saved parks, or join with a code.
- The join screen takes the code (case, spaces and dashes do not matter) and shows each stage in words: joining, getting the host's park, building it. A refusal (no park with that code, a full park, another version or other mods) is said in words.
- Cancelling, or going back, leaves whatever the server already gave, also while the park is being built.
- A game that cannot follow a shared park says why and sends nothing: another edition is told that only Theme Park World parks are shared, and a run with developer options that change the park is told to restart without them.
- When the shared park ends for a guest (the host left, a removal, a lost connection), the guest hears why over the park and goes back to the lobby; the host's park is never saved on the guest's computer.
- A guest is asked before Exit To Lobby leaves a running shared park, and the guest's own status line shows the park, its host and the players.
- All new texts are in eleven languages.
