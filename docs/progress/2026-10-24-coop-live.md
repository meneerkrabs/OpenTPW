## Two games share a park live through the real server (October 24, 2026)

The shared park now has a live acceptance ([COOP.md](../COOP.md), "The live acceptance"; `[EXT:online-coop-session]`). This is C2d-5a: two desktop games share Jungle through the real server, with the game's data, and every step goes through the game's own screens.

- `scripts/coop-live.sh` starts the server and two silent, offscreen games with throwaway players. The host shares its park from the pause menu; the guest logs in from the lobby and joins with the host's code.
- The two games check each other: the same session, the guest's park built from the host's, the host's path line in the guest's park with its digests compared, the guest's own line refused, the figures and their names seen both ways, a chat line each way, a ride, Go to, and the end of the session.
- Three scenarios: the baseline; a server crash and restart in the middle, after which both games come back and go on; and half an hour at the fastest speed.
- The drivers' local server now forwards the chat and co-op sockets, so the browser's pages can take part next (C2d-5b). The browser workflow checks the co-op link through it.
- Each game of an automated run can keep its saves in a folder of its own (`OPENTPW_SAVE_DIR`).
