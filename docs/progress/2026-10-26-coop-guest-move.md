## A guest moves objects in the shared park (October 26, 2026)

A granted guest in a shared park can now use the Move tool on an object ([COOP.md](../COOP.md), "Building by every player"; `[EXT:online-coop-commands]`, `[EXT:online-coop-permissions]`). This is C3b-2.

- **The Move button.** It sends the pick-up to the host. Once it comes back, the Move tool arms with the object's type at its angle, as for the host. Escape, a right click or another tool leaves the wait. The object then stays sold, as a cancelled Move leaves it for the host.
- **Placements and the tool's end.** A placement waits as any guest placement does, and Ctrl keeps the tool for another. The tool's end goes to the host, even when the host has taken the guest's building rights back meanwhile.
- **One pick-up at a time.** A guest has one pick-up open at a time.
- **Carries without a tool.** A guest whose type is carried without its tool (a pick-up left while it waited, an end the host could not take, a resync) ends that carry by itself.
- **Departures.** When a guest leaves, or another player takes its seat while the host was away, the host releases what that seat carried and takes its grant back before the seat's next player can act.
- **No claim needed.** Moving needs no claim: the pick-up is one step, after which the object is gone, so a second pick-up or a sale of it finds nothing.
