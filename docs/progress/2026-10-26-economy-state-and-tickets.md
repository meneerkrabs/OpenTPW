## Economy state and tickets follow tp.exe (October 26, 2026)

Fidelity round 9, package R9-C. It read the ride state word, the player ticket account, the queue and exit tests, the constructor's track word and the x87 control word in tp.exe, and ported what they say.

- **ECON-023, one ride state word.** The economy record and the visitor bridge now share one `RideStateWord` (`+0x19C`: 0 idle, 1 broken down, 4 condemned). The ride update writes it when it reads VAR_BROKEN in state 0 (`0x4E14E0`, state 4 for a life gauge byte of 0), the repair and every opener write `SetState(0)` (`OriginalObjectRuntime.Open`: `0x4DE487`, `0x4DF438`, `0x4DFCB8`, `0x4E003C`, `0x4E01B6`), and the economy, the guests, the object window and the opening guard read it. The guard reads the word, not VAR_BROKEN (`0x4DF290`), and the park points counts-test reads the word too (`0x4DD920`). The saved import state is kept as saved. The park save holds the word as an optional field; an older save derives it from the broken-down flag and the life gauge. The level publishes the entry into state 1 to the economy once, as before. State 2 (a bought upgrade) is still read from the pending level and state 3 from the type, so ECON-023 stays narrowed; the headless breakdown stays `[EXT:headless-economy-breakdown]`.
- **UI-051, the ticket account.** While a park is part of its player's progress, the HUD counter and the purchase check read the player's earned tickets less the spent count (`0x5AF5D0`), and a ticket purchase adds its cost to the ledger's spent count and records the item in the player's bought set (`0x4D4AD0` -> `0x5AF740`, `0x5AF780`). The older purchases of a park saved before enter the ledger once, by identity, never twice. A park outside the player's progress (the sandbox, Instant Action, a co-op session, a read-only visit) counts its own tickets; UI-051 stays narrowed to that.
- **ECON-049, the zero front and the exit test.** A queue ride whose entry has no cardinal link bit has no front, and the opening guard and the object window read it as unconnected (`0x4DE040`, `0x4DE130`, `0x4DE4A0`). The object window shows EXIT NOT CONNECTED from the exit test (`0x4DE5A0`, `0x485F60`): the exit cell's link byte, the cell in front of it and the edge test `0x4D8750` in the three other directions. Untyped exits and entrances keep the permissive answer. The sandbox smoke's track rides are placed with their access cells and their queue is ended on a path, as a player does, instead of relying on the permissive answer.
- **ARRIVAL-003 retired.** The attraction constructor stores 1 in the track word `+0x2C` (`0x4DB0DF`) for every ride, and only a circuit walk (`0x524D1B`, `0x52694F`, `0x526BE1`, `0x526F13`) or a track edit's clear (`0x5251B8`, `0x5257FB`) rewrites it. OpenTPW's controller starts at 1 now. The placement itself walks nothing in tp.exe; OpenTPW's placement walk stays `[EXT:track-placement-walk]`.
- **ECON-059 retired.** The economy runs on the main thread (the only thread starters are the C runtime's `_beginthread` and `_beginthreadex`, called from the library helpers), whose x87 control word is `0x7F` after DirectDraw's `DDSCL_FPUSETUP` and the D3DIM device creation. The renderer `0x576EC0` saves and restores it, and bit 1 of the render-state word `0x8BD508` (the extended-precision restore `0x591250`) is set by no writer (initial value `0x3000141`, every other store ORs or clears other bits), so no path leaves another precision. The goods cost keeps its single-precision steps and needs no oracle target.
- **SAVE-007 retired.** The 11 corpus labs are pinned (projects, started and researched counts, effort split, work load, current projects, highest groups and the object controls' agreement). A project of an object the archives lack and a current project the picker would not offer are reported as "Research not imported" and occur in no corpus save.
- **Determinism.** The pinned fixed-run hashes do not move. **Co-op.** The command shapes are unchanged; a shared park keeps spending its own tickets.
- **Tests.** `RideStateWordTests`, `RideStateRulesTests` (the saved word, a condemned ride, an older save), `PlayerTicketWalletTests` (the counter with global, local and secret tickets and a moved global ticket, the spend, the save and load, the older park, a shared park), `ExitConnectedTests`, `TypedQueueFrontTests` (the zero front is unconnected), `BumpControllerTests` (the track word), `OriginalSaveImportCorpusTests.TheElevenCorpusLabsArePinned`.
