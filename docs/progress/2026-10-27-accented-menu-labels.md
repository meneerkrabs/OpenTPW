## Accented online-menu labels keep the menu font (October 27, 2026)

The native front-end smoke failed its "drawn in the menu font family" check on the online menu in French, Polish, Hebrew, Swedish and Danish (it passed in the other six languages). The font selection was right: OpenTPW takes the menu role from the language's own MENU files, as tp.exe takes its menu slot from the language's font bank. The button-text fit was wrong.

- **Diacritics inside the line box no longer shrink a label.** `UiContext.InkBox` counted every drawn pixel vertically. The MENU, TITLE and SESH fonts keep the rows between the line top and their capitals for marks (MENUSMALL's letters start at row 9; French î and Swedish/Danish å reach row 4 or 5, Polish ń row 7, Hebrew lamed one row above the font's letter box). At 1280x720 the online menu's 30 px label box held the 30 px letter box exactly, so "Boîte de réception", "Logga in på TPW", "Læg park ud på nettet" and "Usuń konto" fell to the plain body font, smaller than their neighbours and on a lower baseline. Vertically the box is now the font's letter box, widened only by ink that leaves the BF4 line box (the GAME fonts' marks above row 0 still count); the original's text library stacks lines a line height apart (0x6ae1c0), so a mark inside the line box never meets the line above.
- **Wider online menu window.** Hebrew's login line is UITEXT 235, "מתחבר אל www.ThemeParkWorld.com" (the original's "Online Login"), 438 px of ink in MENUSMALL against a 407 px label box. The window is now 1280 units wide instead of 1200 (label box 948 units, 444 px at 720p); the buttons keep their 130-unit margins.
- **Refactor.** The menu's ids and labels are a static table (`OnlineScreens.MenuEntries`, `MenuButtonBounds`), and the purple text button's label box is `UiButton.PurpleLabelRect`, so the test measures the same boxes the screen draws.
- **Tests.** `OnlineMenuLabelFitTests.EveryLabelKeepsTheMenuFontFamilyInEveryLanguage` (with `OPENTPW_LANGUAGE_PACK` and `OPENTPW_GAME_PATH`) draws every label, logged in and out, in all eleven UI languages at 1280x720, 1920x1080, 2560x1440 and a Retina 3024x1686. On the old code it reports exactly the five failing languages (seven label/size failures); with the fix it passes. The native front-end smoke passes in Hebrew, Polish, Swedish, Danish, French and English.
- **Still open.** Several online labels have no Hebrew supplementary text and show in English (News, Inbox, Chat, Import file, Delete account); unrelated to this fix.
