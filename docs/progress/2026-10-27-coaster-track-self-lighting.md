## Coaster track texture lighting uses the existing self-lit shader path (October 27, 2026)

Bounded implementation candidate from proposal #569 (COAST-026), inspected against main `60c941de233ac45a0d8c7d680aef2269f655b8b6`. The self-lit shader path landed in #863, but the extruded coaster track still supplied only texture indices: its parsed `asTextureData.bIsSelfIlluminating` values and the three appended marker textures never reached that path.

- `CoasterRenderer.TrackVertex` carries the lighting metadata into the actual engine vertices used by both the fixed and scrolling track meshes. Ordinary textures stay lit; declared self-lit textures and the `m_erase`, `red` and `blue` markers carry `TextureSlotAddressing.SelfLitFlag`. Geometry, normals, texture indices, UVs, scroll timing, addressing, alpha/blend and culling rules are unchanged.
- The existing evening policy is reused, not redefined: a declared self-lit texture also gets `LightSourceFlag` only when `TextureSlotAddressing.IsLightSource` identifies its name. Other self-lit textures and the three build markers keep the existing night tint. No shader or light-source name list changes.
- Three added methods in `CoasterPresentationTests` define eight asset-free cases: four combinations of fixed/scrolling and self-lit/plain textures (including a named glow texture), each of the three marker textures, and invalid/missing texture metadata. The tests use synthetic settings and mesh extrusion and check the complete output flags plus preserved geometry and texture coordinates.
- Validation during preparation: source/API inspection, targeted static wiring assertions, whitespace checks and patch application checks passed. C# compilation/tests, GPU rendering and browser checks were not run in this environment; no .NET executable was available on PATH. Independent review and exact-revision executable checks remain pending.

This is not full COAST-026 acceptance or retirement. Sample-coordinate section runs, flume dry/wet blending, marker transition topology, kept-invalid-node marker evidence, remaining scroll readers and Add-mode model UV animation remain outside this slice. No original executable or game media was read, run or included.
