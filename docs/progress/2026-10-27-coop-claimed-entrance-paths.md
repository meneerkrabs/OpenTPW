## A claim keeps the path cell linked into its ride's entrance (October 27, 2026)

In a shared park, clearing a path cell that links into a ride's entrance cell runs that ride's re-evaluation, as the original's clear does (tp.exe `0x53694B`): the ride's queue is recomputed, a block is stamped, and a closed ride may open. Until now another player could do that to a ride someone else claimed, for example with a remove click or Backspace on the path in front of a claimed kart ride. Such a cell is now the claim holder's alone, as the path cell a claimed queue joins already was ([COOP.md](../COOP.md), "Building by every player" and "Claims"; `[EXT:online-coop-claims]`).

- **What refuses it.** The remove click, Backspace, the host's single-cell removal, the undo of a path line that built the cell, queue lines and native queue segments laid over it, placements (the paths under them, a queue ride's first queue cell and a fresh kart or water station's exit and entry tiles) and kart or water track lines over it. The area clear leaves it standing. Every other player is refused, the host included, in the claim's words ("Another player is editing this ride.").
- **Only a real link counts.** The rights ask exactly what the clear does: a path cell with a cardinal link into an entrance cell whose owner word belongs to the claimed ride. A path cell beside the entrance that does not link into it, a queue cell there, a queue line that only ends on the cell, a path line along it and an undo that only counts it down stay anyone's.
- **One helper.** `CoopBuildRights.BesideClaimedEntrance` was first written for C5's take-backs, on a branch that is not merged yet. This change brings it to main with the path-cell and link conditions above, and every command that clears a path cell asks it.

Verification: four new tests. A session test covers the guest's remove click and Backspace beside a kart ride the host claims: they are refused with the claim's note and nothing changes; once the claim is let go, both take the cell and the ride is re-evaluated on both parks. A rights test covers every clearing command for a guest, the host and the claim's holder, and an execution test covers the area clear. A preflight test covers the fresh station's exit and entry cells for both track families and all four rotations. All 437 co-op tests pass. Reverting each of the eight parts of the change on its own fails at least one of the new tests.

Still open: the coaster tool's cell markers, which clear a path cell where they land, ask no claim for it, as before for a claimed queue's join.
