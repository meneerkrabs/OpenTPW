## Cells under track: path and queue cells over tiles, the demolition's record clear, the station's footprint (October 28, 2026)

Fidelity round 10, package B (the follow-up of round 9's package H). The map's type byte and the track layer now hold both what the original keeps in two layers, the demolition clears the second layer's records as tp.exe's pass 2 does, and a kart or water station's footprint cells count as the executable's net worth counts them (`docs/reverse/ORACLE.md`, findings X37 and X38).

- **QUEUE-012 (narrowed).** The type byte shows a track tile only while the cell's own type is empty (`ParkCellMap.PrimaryTypeAt`); a path or queue cell laid over a straight or stub tile is the cell's type with the tile beneath it, a corner, junction or post refuses (the validator `0x535670` reads the record apart), clearing the cell shows the tile again, a record clear leaves the path over it, an object is refused over such a path, and the queue pass's residues and the saves accept the byte. The owner priority `0x818C14` (reset `0x523522`) and the latches (reset `0x5234F2/F8`, `0x527C52/5C`, `0x52F11B/21`) are read: they belong to one pass over a line, which the path tool's line walk carries, and they change no answer of the queue tool's lines. The native reducer refuses the ride's own two-link queue cell and any queue cell the ride does not own, as the validator does: the three tests that broke in PR #886 built a queue joined to a path and entered the tool without the queue edit that takes the link off, a state the original's tool never starts from; their fixture is unjoined and the ride window's queue button takes the same edit as a click on a queue cell. Still open: the per-cell route of rides without an owner word, the host's terrain source, and the bridge of a tile a path is laid over (TRACK-010).
- **ECON-050 (narrowed).** The demolition's pass 2 now also runs the record clear `0x53B280(0, 0, 1)` on the second layer's record under every cell of the object's shape: **an add-on that is sold or bulldozed takes the tile it stands on with it** (the earlier reading, that the sale only clears the flag, was the variant only a tile's own clear passes, `0x53B703`), with the refund and the arms of the tiles beside it, and a ride's demolition clears its station tiles through the same clear (`TrackEditor.ClearUnderDemolition`). 17 cases of both families are replayed from the executable's own run. A guest may not remove an add-on whose ride another seat claims. Still open: the queue's corner stack replay and which tile the track tool's stale exit and entry globals name at the bulldozer's click (the ride's own is taken).
- **ECON-026 (retired).** The placement commit `0x528A70` stamps type 4 on the footprint cells before the station line writes the second layer, so the eight cells under a station's tiles count 0 + 50, not 2 + 50, and an add-on's four cells count as type 4 under their tile; `ParkCellMap.WriteFootprint` keeps the stamped type as the tile's base type (a restored older save gets it too). Every cell and the net worth equal the oracle's (33555 for a kart station, 33547 for a water station, at every rotation).
- **Determinism:** see docs/DETERMINISM.md. New save fields: none (the saves accept a path or queue byte over a track cell); old saves load.
