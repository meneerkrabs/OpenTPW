## UI follow-ups: research knob startup, map, modes, fonts, validator pointers, moon, banner, bridge word (October 29, 2026)

Fidelity round 10, package D2 (the follow-ups of package D, PR #894). Every claim was read in tp.exe; the tpw-decomp research only pointed to where to look.

- **UI-064 (retired).** The research window's workload knob is the slider class whose position setter (vtable slot `0x1c` = `0x66b508` -> `0x66b088`) returns before touching the ball when the raw value is unchanged and the mode is not the refresh -2 (`0x66b201`-`0x66b20d`); the constructor `0x66ad6a` starts raw 0 with the ball at the layout's authored top 399 (row of `0xd2d10`), and no message 0x15 reaches the slider after its base constructor (`0x65bffd`). So an opening with raw 0 keeps the ball at 399 instead of the track bottom 634.
- **UI-100 (narrowed).** The path and queue line previews now carry the validator's end flag: code 0xB (`0x535AE5`, `0x535B3D`, flag `0x816D4C`) is answered for the line's last cell when it is an existing path cell (a one-cell line included, so the path tool over a path shows the end pointer, `0x818688`/`0x820AB8`) and for the ride's own queue cell under the queue tool; the pointer switch `0x52F950` orders link, end, then no-place for a refused line (`0x527950`, latch `0x816D48` set at `0x533933`; a queue stopped only by OpenTPW's own length bound is no refusal), then cash. Open: the end pointer of the kart and water track lines (`0x53A1C6`, track chooser `0x539760`), the `0x539FB6` cash flag of a chooser call that does not refuse, and the crosshair art, which is not in the game data.
- **ECON-030 (narrowed).** The loss banner's animator is read to its cadence and clock: `0x65E72D(table, 0x23)` stores the table, the interval and the clock; the frame message 0x1e is sent down the window tree by the per-frame update `0x658F6C` (called from `0x48A5DF`), `0x65C357` hands it to the stepper `0x65E9A4`, which runs a step when more than 35 ms have passed on `timeGetTime` (`0x65968E`). OpenTPW's `UiWindowAnimation` steps once per drawn frame with the same strict rule, so the banner-timing item is closed; what remains is the co-op owner's decision for the loss scene in shared parks.
- **UI-013 (retired).** The pause-menu measure `0x4929F0` is read to its font pick: the line's font slot (0 for the menus; slots 0 and 2 swap while the word at `0x78b538` is `0x40D`, `0x41A850`), the bank word `0x78b534` and the 24-byte font record at index 13 × bank + slot from `0x78b54c` (handle at +0x14), then the box through `0x6AE1C0` (0x4000 wide without the wrap flag). OpenTPW's text layout box matches that measure; which shipped font serves slot 0 per size tier stays `[EXT:ui-font-tier-by-scale]` (the original's four banks follow its fixed screen modes), so nothing is left to approximate.
