## Queue corner walk and cell rules (October 31, 2026)

Fidelity round 11, package D (the follow-up of #901, #909 and #923). The queue tool's corner walk and a ride's queue demolition are now the executable's own, replayed against it in the x86 oracle (`docs/reverse/ORACLE.md`, findings X44 and X45), the track tool's sticky exit and entry globals are ported, and a typed world stops answering the opening guard, the exit status and the queue validator with OpenTPW's own rules. The tp.exe reads are mine; the tpw-decomp research only pointed to the code.

- **QUEUE-015 (narrowed).** `QueueCornerWalk` is `0x530120`: the stack (0x401 points at most), the counters of the cells it visits, the link clear where it ends on a path (not when the cell before is the entrance), the line start, the foreign-owner and no-link endings and the wrap of the 16-bit cell word past the map's edge; 82 oracle cases agree on every stack and cell. Its callers are the queue edit click `0x52610A`, the Move pick-up `0x48D006` and the ride's demolition `0x527F9A`, so the placement, the ride window's button and a completion run no walk in the original either. The Move pick-up also reaches the demolition `0x527EE0` through its click (`0x48D03D`, mode 0x33 to `0x525E7F`), which runs the demolition's own walk a second time; that second walk, the stack copy `0x52FC30` and the cells a Move strands are not ported (a stranded cell stays as a stray cell of the ride's owner word, as after any demolition). A typed ride's demolition replays `0x527EE0` (`QueuePaths.DemolishQueue`): the walk, Back with the forced-clear flag while the cached size is above 0, the cell remover's credits (only for cells whose owner cell is not empty; the remover leaves the neighbours' links), one cell's debit, and **the cells the walk does not reach stay** (a stray cell of the ride, everything beyond a junction): 42 oracle cases agree. A ride whose front holds no queue cell pops its front twice and is debited one cell, as the original does. Left: the stack the placement's, the window button's and a completion's clicks leave.
- **ECON-050 (retired).** The queue is cleared by the corner stack replay as above. The track tool's globals `0x7639E0/E4` and `0x7639E8/EC` are a level-wide state (`TrackToolGlobals`) that a select (`Level.Selection`, an add-on selecting its ride), a track tool start and the Buy Land start write and nothing resets; the record clear spares the tiles they name, whichever ride that was, so selling an add-on on a ride's exit tile destroys the tile unless that ride was the last one selected. The globals are the issuer's client-side state, kept across park loads in one process run and in no save; the five demolishing and selling commands carry the issuer's tiles (`ToolTiles`, command format 7), the commands' execution applies them, so replays and peers agree (no co-op fallback). The placement commit resets the exit to (-1, -1) and selects only where `0x528F36`/`0x5296EA` do, Buy Land's select takes the gate-post branch (entry `(post.X - 2, post.Y + 1)`), and only the 19 callers of `0x5276D0` select; the owner leases against the original's commits into other rides' cells stay `[EXT:track-tool-owner-leases]`; a map without a level and the harness worlds are `[EXT:untyped-harness-world]`.
- **QUEUE-003 (narrowed).** The cached back and size (`+0x3A`, `+0x40`) are kept by the host's own syncs (the queue commands' pre-edit sync, the walk's and the demolition's reads, the one-click removal's lookup) and dropped only where the executable calls `0x4DE1F0`; the legacy per-cell builder and the access-cell re-resolution still recompute.
- **QUEUE-012 (narrowed).** A typed world asks the cell validator `0x535670` alone (it reads no terrain); Theme Park Inc layouts, visits and harness worlds keep OpenTPW's terrain rule on top.
- **ECON-049 (narrowed).** In a typed world the opening guard reads the executable's cells: a queue ride's cached back cell is tested whatever its type (a path front is tested on its own link byte, an empty one is unconnected), a ride without a queue needs its access cell's link toward the rotation's path cell and that cell's link back (no owner word or entrance type read), and the exit status compares the exit with the access cell. Theme Park Inc layouts and untyped worlds keep the permissive answers; a sideways step off the map's edge wraps the 16-bit cell word as the original does (a word inside the array is read); only words outside the array, odd rotations and the null reads at `0x4D97E0`/`0x4D96F0` are answered connected under `[EXT:original-undefined-reads]`. Refunds follow the demolished ride's owner word, each cell at its owner's scrap percentage.
