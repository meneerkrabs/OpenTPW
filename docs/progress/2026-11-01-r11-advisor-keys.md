## Advisor records, All Staff window and lobby advisor (November 1, 2026)

Round 11 package V reads the advisor's records, the All Staff window and the lobby in tp.exe (REA, `dis.py`; the Mac decomp only pointed to the code).

- **GUEST-007 (retired), ADVISOR-009 (retired)**: the queued advice record keeps the two words `0x59B590` stores (id word +0x0, dword +0x4): through the queue, an own park save (optional, written only when not 0) and an original save, with the producers filling them as the original's call sites do (the prank handler `0x59B25F..0x59B3F4`: the guest's id and the cell word y x 128 + x + 1; the ride lines `0x4DF8BE`, `0x4DADC0`, `0x4DA6C5`: the ride's id and its type id; the research lines `0x59B0C6`: the project's id word). Their readers are the speech and the caption formatter. The speech (`0x59B620`) scores a scanned message again through `0x59C0A0` (`0x59B6BE`), says nothing below `MinScoreForConsideration` (`0x59B6C3`, signed: a score equal to it passes) and copies the nonzero words the callback left into the record; the F1 replay's score-overridden byte (+0x16, `0x59B870`) skips the check and is now kept. The category-24 message carries the words to the tag system, whose formatter `0x509E10` reads them: the advisor's response rows use the tag kinds 0 (no arguments), 2 (the object type named by the dword's low word: the ride lines 66, 68, 69, 70 and the research lines 93-97) and 5 to 8 (the golden ticket wins, which read the park's thresholds `0x785790`, `0x785794`, `0x7857A0`, `0x7857A4`/`0x7857A8`, not the record), so the 36 captions with parameter slots (194-206, 248-256, 316-317, 434-463) are posted now with their arguments (`content/data/advisor-captions.toml` has the kind column, written by `tpw_exe_tables.py`). The scan callbacks' own words (messages 86-89, 113, 140, 238-256) reach rows of kind 0 or without a caption, so nothing reads them. The researchers' flag message is of type 0x13 with the value 5 or 6 (`0x40F630`): the advisor's handler `0x59AE20` ignores both (jump table `0x59AF98`: only 0, 2, 3, 4 and 10 act), so the lab flag reaches no advice; the type-5 case of `0x59B060` queues the record a golden ticket message carries. The breakdown handler's second site for advice 70 (a mechanic already on the ride, the ride not called for: `0x4DAEE1`, `0x4DAF7E`) is ported in `AdvisorRideEvents.ForBreakdown`. No pin moves (the advisor is presentation, not hashed).
