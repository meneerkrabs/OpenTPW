## Lobby key panel and the lobby advisor (November 1, 2026)

Round 11 package V, lobby part, read in tp.exe (REA, `dis.py`; the Mac decomp only pointed to the code).

- **ADVISOR-025 (narrowed), PTCL-908 (lobby part retired)**: the lobby's key panel is ported as the static reading has it (`FrontEndMenu.KeyPanel.cs`, `LobbyKeyPanelEffect`, [the contract](../reverse/LOBBY-KEY-PANEL.md)). The key frame `s_key` (EA) and its cost digit `s_X1` (EB) are gold while the player's keys meet the selected island's `global.sam` `Keys.CostToEnter` (Jungle 1, Halloween 1, Fantasy 3, Space 5) and grey below it (frame 0 and cost - 1, or frame 1 and cost + 4: `0x4B9340`), the screen-space effect `0x61` runs while they do (created once, ended below the cost and with the lobby), every island change repeats that step with the stored count (`0x4B90F0`), and the counter's icon is at the frame the creation sets (3, `0x4B8D65`), with `"%d x"` written only for keys above 0. `0x4B8EE0`'s show branch has no caller.
- **The lobby advisor (ported)**: the original runs the advisor in every frame of the front-end state (`0x54E6DF`, `0x54E6E6`), so the lobby has it now (`LobbyAdvisor`, [the account](../reverse/LOBBY-ADVISOR.md)): the global advisor shows bottom right over every lobby screen while a line plays, through the queue task `0x5D5F80` (`LobbyAdvisorQueue`) with the idle line, response 394 or 395 after 90 s of silence (`0x5E1830`, a local draw for the original's `rand()`), cut off with the slap sound when the lobby goes (`0x5D6060`, `0x5994E0`). It is made when the first line is said, off with `--no-advisor` and with the advisor option.
- **ADVISOR-005 (retired)**: the advisor is lit by the active lobby screen's ambient words, 0.267 grey (`0x444444`) on the island screens (`0x5E1924`, `0x5E13A9`, `0x5E2445`) and 0.125 grey (`0x202020`) on the globe and city views (`0x5DCFE0`, called by both enters), through the advisor shader's ambient slot (`Advisor.Ambient`). The fog the island screens switch on (`0x5D9680`, 50 to 250) does not reach it: its vertices are at depth 0.2, inside the start (`0x581790`).
- **Lobby sequences 28 and 29**: only sequence 28 is reachable in the lobby, through response 393 (`0x4A6B4F`, when the first player's dialog closes after `0x5AFC30` added the first key). OpenTPW publishes its starter key only when the lobby is retired for the park, so 393 is not said, nor the lines of the player-select and name dialogs (390, 391, 398, 570), the postcard windows (592 to 597), the online globe (598) and command 10 of the lobby menu (600). Sequence 29 is the park's golden ticket lines.
