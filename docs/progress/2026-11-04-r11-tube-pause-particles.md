## Message tube, pause window and UI particles (November 4, 2026)

Round 11 package N reads the message tube's tag windows, the P window and the UI particles in tp.exe (REA, `dis.py`; the Mac decomp only pointed to the code).

- **UI-025 (narrowed)**: the tube is the original's tag window system. Every post names a tag; the tag table (`content/data/message-tags.toml`, the 32-byte records from `0x75ECA8`, written by `tpw_exe_tables.py`) gives the replacement, icon, actions and lifetime (30 s for most tags, 90 s for the offers, none for progress rows). A row is kept when it is read (`0x48D9C0` removes nothing; it stops an armed non-offer tag's timers) and leaves only by delete, answer, expiry or replacement; a delete, expiry or answer removes it 500 ms later (`0x4A13E8`), a replacement at once. A right click on the tag whose panel is still sliding out does nothing (`0x7CA094`), one on the tube's body removes every row 100 ms apart (`0x4A1190`, `0x100003`), the bomb is hidden on offers, and the panel's buttons come from the tag's actions (`0x48E610`, `0x48E0F0`: buy, hire, loans, research, park information, staff costs, entry price). The tube is saved with its tags and an original save's UI block (count, then 0x21C-byte records, `0x48EE50`/`0x48EF70`) is imported; the loader's open byte is never read, so every row restarts its timers (an earlier note said otherwise). Left: the locate and call-mechanic actions (3, 4, 23), the place of the `0x5A` burst, the bounce animations and writing the original's tag block.
- **ECON-058 (narrowed)**: the tag timers are the original's UI timers (`UiTimer`, `0x661FE5`: interval, origin, enabled, signed 32-bit differences, a disabled timer's origin still advances, resume resets every origin). The pause owners suspend them as in tp.exe: the P key and the focus loss too (`0x4092A0(1)` -> `0x481440` -> `0x48A6E0` -> `0x662411`), which the earlier mapping left out.
- **PATH-017 (narrowed)**: the P window is drawn (the full-canvas `lolight` model over the windows that existed, then the `paused` banner of table `0x752E00` animating by table `0x752ED0`), and as it holds the focus no key, text or wheel reaches the screens below it. The click dispatcher `0x4879D0` acts on the stored hover cell (`0x7B05CC`); the alternate buffered-input mode is not read.
- **PTCL-908, UI part (narrowed)**: the tag windows' effects are wired. A first show starts the burst `0x5A`, the warning timer starts the retained `0x5B` five seconds before the expiry; both at the icon's centre in the level's pool, hidden, moved and ended with the window.

No pinned hash moved (tube and particles are HUD state outside the hash). Old saves and command logs load and replay as before; the tube's new row fields are optional and validated.
