## Original texture page rectangle allocator (November 8, 2026)

Ported tp.exe's rectangle allocator `0x58ECA0`, rank refresh `0x58CB40` and unsigned-key sort `0x57D090`/`0x57CED0` as an internal managed building block (`OriginalPageAllocator`). An independent, identity-gated x86 oracle runs the original routines without stubs on 376 synthetic cases, including a rank boundary that distinguishes single- from double-precision arithmetic; numeric golden rows check placements, partial failures, the 127-item cap, leftover 8/9 boundaries, alignment/padding, reduction and signed-rank reinsertion, unsigned free-key ties and float rank boundaries (ORACLE.md X91, section 7.43).

No renderer calls this helper yet; this standalone building block does not retire or narrow UI-004 by itself, and the register is unchanged. The exact pending/existing merge, shared world/UI page orchestration and lifetime, control visibility order and joint deferred-sort inputs remain required before changing UI-004's runtime ordering. Width classes alone are not page identities; no shelf-packing replacement, new APPROX/EXT, save field or determinism pin is introduced. Filtered golden/adjacent UI tests and source/evidence checks verify this non-rendering milestone; full game suites, native smokes and browser preview cannot exercise its unconnected runtime path and are not claimed as verification.
