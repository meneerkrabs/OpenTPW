## Page-list merge before texture packing (November 8, 2026)

Ported tp.exe's pre-packing list merge `0x58EAE0` as an internal managed building block (`OriginalPageListMerge`, on top of `OriginalPageAllocator`). It merges a pending list with an existing list whose records must carry flag `0x40000000`, drops device-dependent records, orders the result descending by two signed ordering words and returns the emitted area. An independent, identity-gated x86 oracle runs the original merge and its predicate with no stubs on 140 synthetic cases, including every filter, the one-shot leading skip, tie and negative ordering, and wrapping area sums (ORACLE.md X92, section 7.44). The managed port reproduces every native row.

No renderer calls this helper yet, and this standalone building block does not retire or narrow UI-004 by itself; the register is unchanged. Still required before any runtime page grouping: the orchestration `0x58F190` with its real page sizes, shared world/UI page membership and texture lifecycle, and the persistent control show order. The two ordering words are ported as the routine reads them; what fills them in a running scene is not established here, so no width-only grouping or other substitute is introduced. No new APPROX/EXT, save field or determinism pin. Filtered golden and adjacent UI tests plus source/evidence checks verify this non-rendering milestone; full game suites, native smokes and browser preview cannot exercise its unconnected runtime path.
