## RIDES-011: the type-3 tail gets its test (November 11, 2026)

The branch that stores the clicked thing's raw anchor while a coaster track add-on is armed was implemented without a test, because the test park applies its extra settings globally and so leaves no catalogue entry an add-on. The fixture is possible with the synthetic entry the coaster tests already use: an `ObjectCatalogEntry` built from settings text carrying `AddOn.UpgradesId` at the ride's info id, `AddOn.UpgradeType` at the track type and `Bumper.WhichTrackType 3`.

`ACoasterTrackAddOnSelectStoresTheRawAnchor` arms that add-on with `BeginAddOn`, runs the select and asserts both pairs hold the ride's raw anchor rather than the mapped station cells. Removing the branch fails the test, so it pins the behaviour rather than the setup.
