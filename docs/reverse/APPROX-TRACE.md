# APPROX trace against the Mac binary

2026-10-09. Nine Haiku subagents searched the decompiled Mac PowerPC executable and nine
shared libraries (`SimThemePark.data` SHA-256 `04809cd4…e295f5`; libraries as in FINDINGS.md;
`online shared` could not be imported by Ghidra) for each of the 141 approximations in
FIDELITY-REGISTER.md. Each claim had to cite functions and 2–6 exact substrings (anchors) of
their decompiled text; a script checked every anchor against the cited function. No
decompiled code is stored here.

Result: 98 not found, 43 with a verdict. Anchor check: confirmed verified: 2, contradicted failed: 3, contradicted verified: 15, partially_confirmed failed: 4, partially_confirmed verified: 19.

**Status.** A passed anchor check proves the cited code exists, not that the reading is right.
The lead analyst read the code around the anchors for the IDs marked in the *Lead review*
column; the others are leads. Only ECON-007 and part of ADVISOR-013 changed status
(BIN labels); every contradicted rule stays APPROX until OpenTPW implements the traced
behaviour.
