Install OpenTPW

Bring your own copy of Theme Park World / Sim Theme Park (1999), download OpenTPW and choose the folder with the original game files. You can also play in your browser.

OpenTPW is a development preview. It already runs parks, guests, rides, sound and the original interface, but the complete original game is still being reconstructed. Check the feature matrix for current limits.

1. Get your game files ready

You need your own legal copy of the original game: an installed copy, a copy of your CD, or the mounted CD itself. OpenTPW contains none of the original game files and does not download them for you. You do not need to run the original executable.

Find the folder that contains Data. It should look like this; the spelling and letter case can differ:

Theme Park World/
└── Data/
    ├── levels/
    ├── global/
    └── Language/
        └── English/

Choose Theme Park World in setup. Selecting Data itself also works: OpenTPW finds its parent. At least one language folder must be present.

Theme Park Inc / Sim Coaster (2001) is a different game. Its files are not a replacement for Theme Park World. OpenTPW offers an experimental building-and-guests route, including an explicit browser start. Follow the Theme Park Inc launch guide for the current desktop command, upcoming edition chooser and limitations; it does not promise the full TPI campaign or native saves. Other editions and modified folders may have compatibility differences.

2. Choose a download

These links download the latest published release. The packages include the .NET runtime, so you do not need to install .NET separately. Pick the package for your operating system and processor, then extract the whole archive.

The release page has release notes, earlier versions, separately marked previews and SHA256SUMS.txt for checking the downloads.

Windows

  1. Extract the downloaded ZIP into a folder you can write to, such as a folder under your user account.
  2. Open the extracted OpenTPW-win-… folder and run OpenTPW.exe. Keep the other extracted files beside it.
  3. Continue with first start below.

The Windows build uses Direct3D 11. You do not need Parallels or another virtual machine when running the native macOS or Linux package.

macOS (Apple silicon)

  1. Extract OpenTPW-osx-arm64.tar.gz. Finder can open the archive.
  2. Open Terminal and change into the extracted folder. For example, if you extracted it in Downloads:
cd ~/Downloads/OpenTPW-osx-arm64
./OpenTPW

The package is unsigned and is not notarized. If macOS blocks the downloaded files, after checking that this is the OpenTPW release you downloaded, run this once from inside the extracted folder, then start it again:

xattr -dr com.apple.quarantine .
./OpenTPW

The release includes SDL2 and uses Metal. Homebrew and Rosetta are not required for the Apple silicon release.

Linux

Install your distribution's SDL2 library, Vulkan loader and graphics driver. On Debian or Ubuntu, the SDL2 and loader packages are libsdl2-2.0-0 and libvulkan1. Mesa-based graphics use mesa-vulkan-drivers; other GPUs may need their vendor's Vulkan driver. Run OpenTPW in a desktop session.

Extract the archive for your processor and start the executable in its folder. For the x64 download:

tar -xzf OpenTPW-linux-x64.tar.gz
cd OpenTPW-linux-x64
./OpenTPW

For ARM64, replace linux-x64 with linux-arm64. If the executable lost its permission when copied, use chmod +x OpenTPW. The build uses Vulkan.

3. Choose the game folder

  1. OpenTPW searches for an existing Theme Park World folder. If setup lists your copy, choose Use. Otherwise choose Choose a folder.
  2. Browse to the folder that contains Data, type its path, or drag the folder onto the setup window. The window checks the files and shows any missing data.
  3. Follow the setup window to its summary and finish. OpenTPW remembers your folder for the next start.

If your files include the original CD launcher, choose Play to continue. In the game lobby, select an island to start a park. For the full setup behaviour, see first-run setup.

To change folders later, open Options → Game files, then restart OpenTPW. To open the setup window again, start the executable with --setup.

You can also choose the folder directly from the command line:

# macOS / Linux
./OpenTPW --game-path "/path/to/Theme Park World"

# Windows PowerShell
.\OpenTPW.exe --game-path "C:\Games\Theme Park World"

Optional CD and bonus content

CD: if your installation lacks music or movies, select your CD or extracted CD folder in Options → Game files. A mounted CD can also be the main game folder when it has the required data. Read-only game folders use a save folder under your user configuration directory.

Bonus content: extract your official bonus-content archive and choose the folder that contains its levels folder in the same screen. OpenTPW imports the bonus object files into its configuration directory. Restart to use them. See changing the folders in game and objects and bonus content.

Play in your browser

  1. Open play.opentpw.io.
  2. Choose where your game data comes from. Load from archive.org (one click) streams the CD image of a third-party upload, archive.org/details/tpworld_202508, once (about 713 MB, of which about 320 MB of data files are kept). You choose to load it: OpenTPW ships no game data, reads only data files, and never fetches the upload's executable. Or use another address of a CD image, your own CD image (.iso, .bin with its .cue, or a .zip), or your Theme Park World folder, the one that contains Data. Nothing is fetched before you click, and nothing is uploaded.
  3. Click or press a key to enable sound, then play. Going online is optional.

The browser needs WebGL2 and WebAssembly. Parks, sound and online play run there, and saves and settings are kept in that browser between visits. The game files are kept in that browser too, so your next visit starts with Play and needs no download or folder choice. Movies and developer panels are not available in the browser yet. See the browser version for current limits and privacy for storage details.

Updating OpenTPW

Close OpenTPW, download the new archive for the same system and extract it into a new folder. Start the new executable. Your selected game folder is stored outside the release folder, so setup can reuse it. Keep your original game files and existing saves.

Settings are normally under %APPDATA%\OpenTPW on Windows, ~/Library/Application Support/OpenTPW on macOS, and ~/.config/OpenTPW on Linux (or $XDG_CONFIG_HOME/OpenTPW when set). A custom OPENTPW_CONFIG_DIR overrides this location. Moving to another browser or clearing its site data also removes that browser's saved settings and saves.

Troubleshooting

Setup cannot find the game or says files are missing

Choose the folder manually and check for Data/levels, Data/global and at least one Data/Language subfolder. Extract archives before choosing them. A lone TP.exe is not enough. If an automatic search times out, choose an available local copy manually.

There is no Browse dialog on Linux

The folder dialog uses zenity or kdialog. If neither is installed, type the folder path into the setup field instead.

OpenTPW does not start, or reports a native-library or graphics error

Check that you downloaded the package for your processor and extracted every file. On Linux, check SDL2 and the Vulkan loader and driver. On macOS, use the Apple silicon package and the quarantine step above when needed. Start from a terminal to see the error message. See release packages and running and diagnostics.

Movies, music or some language files are missing

Your installation may not contain all the files from the CD. Add the CD folder under Options → Game files and restart. Browser movies are not implemented yet. See languages, sound and movies.

The CD launcher shows dim Install or Uninstall buttons

OpenTPW reproduces the original launcher when its files are available. Its Play, View Read-me and Exit buttons work; it does not run the original Windows installer. Start with --no-autorun to skip the launcher. See the CD launcher.

I found a bug or a difference from the original game

Report it on GitHub with your OpenTPW version, operating system, processor, game edition and steps to reproduce it. Include the error text if there is one. Keep original game files out of public reports.

Building from source? Use the pinned .NET SDK and follow running the development build. Hosting an online server? Follow server setup.
